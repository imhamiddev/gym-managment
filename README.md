# باشگاه‌یار

اپ اندروید مدیریت باشگاه ورزشی — **Kotlin + Jetpack Compose + Supabase**.
نسخه‌ی وب قبلی (Next.js) حذف شده؛ تاریخچه‌ی گیت کد قدیمی را نگه می‌دارد.

## قابلیت‌ها
**مربی:** ساخت باشگاه و کد دعوت · تایید/رد درخواست عضویت · لیست اعضا با جستجو و فیلتر شهریه · مشخصات و برنامه‌ی تمرینی هر عضو (+ یادداشت خصوصی) · ثبت شهریه با پلن، تاریخ شمسی و ۳۰/۶۰/۹۰ روز · حضور و غیاب · QR ثبت حضور (نمایش، چاپ، اشتراک‌گذاری، تعویض) · تنظیمات (روزها، ساعت، شماره کارت، پلن‌ها) · مربی کمکی

**ورزشکار:** پیوستن با کد باشگاه · روزهای باقی‌مانده‌ی شهریه · برنامه‌ی تمرینی · تاریخچه‌ی حضور و پرداخت · ثبت حضور با اسکن QR داخل اپ · یادآوری پایان شهریه (۲ روز قبل، ۱ روز قبل، روز پایان)

**عمومی:** فقط فارسی (RTL) · تاریخ شمسی · تم روشن/تاریک/سیستم · حالت آفلاین (آخرین اطلاعات ذخیره‌شده نمایش داده می‌شود؛ ثبت تغییرات نیاز به اینترنت دارد)

## راه‌اندازی بک‌اند (یک‌بار)
راهنما در [`supabase/README.md`](supabase/README.md): اجرای فایل SQL و خاموش کردن «Confirm email».

## دریافت APK
از بخش **Releases** همین ریپو فایل `gymyar-<نسخه>.apk` را دانلود و نصب کنید.
(نسخه‌ی `-debug` فقط برای عیب‌یابی است.)

انتشار نسخه‌ی جدید: ساخت تگ، مثلاً

```bash
git tag v1.0.1 && git push origin v1.0.1
```

GitHub Actions به‌صورت خودکار APK امضاشده را می‌سازد و در Releases می‌گذارد.

## ساخت محلی
Android Studio (JDK 17) یا:

```bash
./gradlew assembleDebug      # app/build/outputs/apk/debug
```

## ساختار
```
app/                 اپ اندروید (Compose)
  data/              کلاینت Supabase (Auth + RPC)، کش آفلاین، مدل‌ها
  ui/{auth,coach,athlete,common,components,theme}
  util/              تاریخ شمسی، فرمت فارسی، QR
  work/              یادآوری شهریه (WorkManager)
supabase/            SQL بک‌اند + تست‌ها
keystore/            کلید امضای APK
.github/workflows/   CI و انتشار
```

## نکته‌ی امنیتی
- کلید `anon` داخل اپ است (طراحی Supabase)؛ جدول‌ها از بیرون قابل دسترس نیستند و فقط توابع SQL با بررسی نقش صدا زده می‌شوند.
- کلید امضا (`keystore/`) برای راحتی داخل ریپوی **خصوصی** است. اگر ریپو را عمومی کردی، آن را به GitHub Secrets ببر و کلید را عوض کن.
